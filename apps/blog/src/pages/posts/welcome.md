# Welcome to Minions Proposals

We're excited to introduce **Minions Proposals** — Proposal drafts, answer sets, scoring, and prompt version references.

## What's Included

- **TypeScript SDK**: `npm install @minions-proposals/sdk`
- **Python SDK**: `pip install minions-proposals`
- **CLI**: `npm install -g @minions-proposals/cli`

## Getting Started

Check out the [documentation](https://proposals.minions.help) for a full guide.
