# Minions Proposals

Proposal drafts, answer sets, scoring, and prompt version references

## Overview

This project is part of the [Minions ecosystem](https://github.com/mxn2020/minions) and provides:

- **TypeScript SDK** (`@minions-proposals/sdk`) — Core library for Node.js
- **Python SDK** (`minions-proposals`) — Python bindings
- **CLI Tool** (`@minions-proposals/cli`) — Command-line interface
- **Web App** — Interactive playground at [proposals.minions.wtf](https://proposals.minions.wtf)
